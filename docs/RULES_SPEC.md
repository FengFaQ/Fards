## 1. 对局目标与总部（HQ）

- 胜利条件：**摧毁敌方总部**。`[Z][W][S]` **高**
- 总部**初始防御力 20**。`[Z]`「总部初始为20血」 **高**（已获社区教程明确值）
- **血量上限 99**；**单位攻击力上限 99**。`[Z]` **中**（单一来源，但数值具体；实现建议钳制 0–99）
- 总部位于自己的**支援阵线**。`[W]` **高**
- **总部不是单位，但总部和单位都算作「目标」**。`[Z]` 原文「总部不是单位，但总部和单位都算作目标」 **高**
  - → **「对单位」的效果不能指向总部；「对目标」的效果可以指向总部**。`[Z]` **高**
  - 实现要点：目标筛选需区分 `target_kind = unit | hq | any`。卡面「1 个敌方单位」→ 排除 HQ；「1 个敌方目标」→ 含 HQ。
- 总部可被治疗/加防、可被直接伤害、可被授予持续效果。`[D]`（`the_biscuit_boys`、`kfu_regiment`、`contest_doctrine`） **高**
- 伤害只扣当前防御力，溢出伤害**不转移**（溢出量 = 总伤害 − 目标防御力）。`[Z]` **高**

## 2. 回合结构与开局

**开局** `[Z]` **高**：
1. 抽起始手牌：**先攻 4 张，后攻 5 张**。`[Z]` **高**（本条为正反手唯一差异，已解决此前 ❓）
2. **重新调度（mulligan）一次**：可更换任意张不想要的起始手牌，替换牌洗回卡组后随机补抽等量。`[Z][W]` **高**
3. 先攻方开始第 1 回合。

**单回合流程**（由卡牌时机文本 + [Z] 还原）**高**：
1. **回合开始**：触发「友方回合开始时」；**指挥点回满至槽数**（不累积）；**抽 1 张牌**（牌库空 → 士气伤害，见 §11）。`[Z][W]`
2. **行动阶段**：出牌 / 部署 / 移动 / 攻击，顺序不限。**移动和攻击统称「行动」**。`[Z]` 原文「移动和攻击可以统称为行动」 **高**
3. **回合结束**：触发「友方回合结束时」；**剩余指挥点清零、不保留**。`[Z][W]` **高**

**手牌上限 9 张**：第 10 张起抽到即**爆掉（移出对局）**，不进墓地、不触发亡计。`[Z][W]` **高**

## 3. 克雷迪特 / 指挥点（Kredits）

- 用途：**打出卡牌** + **单位行动（移动和/或攻击，消耗该单位的行动花费 `operation_cost`）**。`[Z][W][S]` **高**
- **每回合自然 +1 槽，自然上限 12 槽**。`[Z][W]` **高**
- **回合开始时回满至槽数**（不是累积余额）。`[Z][W]` **高**
- **回合结束清零，未用完不保留**。`[Z][W]` **高**
- 通过卡牌效果：**槽位最多可到 24**，**单张卡费用最高也可达 24**。`[Z]` **高**（[W] 亦写「最多 24 个指挥点槽」）
- 观测：卡池中最高费用为 **12**（`maus`、`king_tiger`）。`[D]` **高**
- 单位行动花费（`operation_cost`）分布：0→60、1→578、2→257、3→48、4→13、5→2、6→1。`[D]` **高**
  - **绝大多数单位行动花费 = 1**，这是复刻最易漏掉的隐形成本。
- 建模要点：`credits`（当前余额，可被即时增减）与 `max_credits`（槽数，可被 ramp 永久提升；自然封顶 12、绝对封顶 24）**必须分开**。**高**
- 费用减免/增加、失去指挥点、失去槽位均存在。`[D]`（`4_fallschirmjger`、`stranglehold`、`38th_independent`） **高**

**构筑校验算法**（`[K]` 248/248 通过）**高**：
```
total = 39 张卡牌 (+1 HQ, 由引擎侧管理)
ally_count <= 12
per-card count <= COPY_LIMIT[rarity]   # 4/3/2/1
for card in deck:
    if main_faction in card.host_factions: main_count += n
    elif ally_faction in card.host_factions:
        assert card.rarity != "Elite"     # 盟国金卡禁令
        ally_count += n
    else: ILLEGAL
assert main_count + ally_count == 39
```

### 4.1 `host_factions` = **流亡 / 跨阵营可用性**（实现关键）
`[Z]` 明确定义：「流亡牌可投入包含本国的卡组，也可投入包含流亡国的卡组……主英时不消耗盟国卡牌上限数量」——这正是 `host_factions` 数组的语义。
- `orp_byskawica`：`faction=Poland`，`host_factions=[Britain, Poland]` → 英国卡组可当**本国牌**用，**不占** 12 张额度。
- 同类：`m4_firefly_pl` `[USA,Poland]`、`spitfire_mk_v_pl` `[Britain,Poland]`、`1st_grenadier_regiment` `[France,Poland]`、`m_s_406` `[France,Poland]`、`devils_brigade`（`host_factions` 含 Britain）。

### 4.2 `set` / `pool` / `is_*` 语义
- **`set`（扩展包，15 个）**：Base 350、Allegiance 150、OceaniaStorm 118、Homefront 111、BloodAndIron 111、NavalWarfare 106、Breakthrough 105、Legions 105、BrothersInArms 94、CovertOps 87、WinterWar 87、OnlySpawnable 85、WorldAtWar 53、Special 44、TheatersOfWar 40。**高**
  - `[Z]` 给出中文代号与时间线：基础 → 忠诚 → 战区 → 突破 → 军团 → 世纪大战 → 战友 → 冬季战争 → 秘密行动 → 血与铁 → 海战 → 国土防线（并注明「玩家把扩展包也叫赛季」）。
- **`pool`**：
  - `active` 954 = 天梯/休闲可用
  - `reserve` 563 = **预备役**，仅经典模式
  - `derived` 129 = 派生/召唤物，不可构筑
- `is_reserved=true` 与 `pool=reserve` 完全等价（563）；`is_derived=true` 与 `pool=derived` 完全等价（129）。**高**
- ⚠️ **API 怪癖**：`attributes` 含 `OnlySpawnable` 的 44 张 **不是**「不可构筑的衍生卡」——该集合与 `BecomesVeteran:` 老兵底版**完全重合（44/44）**，且其中 **31 张被真实卡组使用**。真正不可构筑的是 `set=OnlySpawnable`（85 张）与 `pool=derived`（129 张）。**高**
- `is_exile=true` 16 张（流亡卡，仍可构筑）。**中**

## 5. 战场：支援阵线 / 前线

| 战线 | 归属 | 槽位 | 说明 |
|---|---|---|---|
| 支援阵线 support line | 双方各自一条，**总部设于此** | **4** | `[Z][W]` **高** |
| 前线 frontline | 双方之间，**共享**，单方占领 | **5** | `[Z][W]` **高** |

**前线占据 / 易主**（`[Z]` 原文，**高**）：
- 当一方单位进入**空置**的前线时，立即**占据**前线。
- 另一方**必须消灭前线所有单位**才能夺回前线控制权。
- **前线有敌方单位时，友方单位不能进入前线**。
- 实现：`frontline_owner = owner of any unit in frontline`；进军前置条件 `frontline_owner == null || frontline_owner == self`。

**移动限制** `[Z]` **高**：
- 不能把单位移动到**对手的支援阵线**。
- 不能把单位移动到自己的**手牌**（除非是撤退/效果）。
- 支援阵线 → 前线需支付行动花费；前线 → 支援阵线（撤退）不需要。

**撤退（retreat）** `[Z][W]` **高**：
- 前线单位撤退 → 回到**本方支援阵线**。
- 若支援阵线**已满**，或**本就从支援阵线撤退** → 返回**所有者手牌**。
- 被控制状态下的单位撤退，返回**原拥有者**手牌。

**控制（control）** `[Z]` **高**：
- 接管控制权后，新控制者可使用该单位。
- **接管时，除非该单位是前线唯一单位，否则移至新控制者的支援阵线**。
- 单位「所有者」不变；卡面「所有者」指向原拥有者。

## 6. 部署 / 加入战场

- 单位从手牌支付费用打出 → 部署到本方**支援阵线**，触发**部署效果**。`[Z][W]` **高**
- ⚠️ **部署效果仅在「通过部署进入战场」时触发**；经「**加入战场**」「**返回战场**」「**转换**」等置入战场的单位**不触发部署效果**。`[Z]` 原文明确 **高**（解决此前 ❓14）
- 「加入手牌」≠「抽牌」：加入手牌是**从总牌池凭空生成**，不消耗卡组；它不是检索。`[Z]` **高**
- 新部署单位默认当回合不能行动，除非有**闪击**。`[Z][W]` **高**
  - ⚠️ 「**行动花费 0**」≠ 拥有闪击；「可在同一回合移动并攻击」也 ≠ 闪击。`[Z]` **高**
- 「被指定/被指向」的兵种目标限制：坦克、步兵、炮兵**都可以选择空军（战斗机+轰炸机）作为攻击目标**。`[Z]` **高**
- 支援阵线满（4）时不能再部署。`[W]` **高**

## 7. 战斗

### 7.1 术语
- **交战**：一个单位**攻击另一个单位**即为交战（**攻击总部不算交战**）。`[Z]` **高** → 「交战时」触发（如重甲）只在单位打单位时生效。
- **被攻击 ≠ 受到伤害**：「被攻击」指单位攻击该目标。`[Z]` **高**
- **行动** = 移动 和/或 攻击。`[Z]` **高**
- **溢出伤害** = 总伤害 − 目标防御力。`[Z]` **高**
- **修复**：完全修复 = 防御力回满至上限（基础防御力 + 增益）。`[Z]` **高**

### 7.2 攻击流程
1. 选攻击者（可行动、未疲惫、未被压制/抑制、非「无法攻击」）。
2. 支付**行动花费**。`[Z][W]` **高**
3. 选合法目标（§7.4）。
4. 结算伤害（含反击/伏击先手/护甲/冲击，§7.3）。
5. 攻击者疲惫；`fury` 可攻击 2 次。
6. 攻击不消耗卡牌。

### 7.3 反击矩阵（`[Z]` 逐兵种原文，**高**）
| 兵种 | 攻击时受到反击？ | 被攻击时造成反击？ |
|---|---|---|
| 步兵 | 是，**目标为轰炸机时除外** | 是，**攻击者为炮兵/轰炸机时除外** |
| 坦克 | 是，**目标为轰炸机时除外** | 是，**攻击者为炮兵/轰炸机时除外** |
| 战斗机 | 是，**目标为轰炸机时除外** | 是，**攻击者为炮兵时除外** |
| 炮兵 | **否** | **否** |
| 轰炸机 | **否**，但**目标为战斗机时是** | **否** |

**可直接实现的判定式**：
```js
function attackerTakesRetaliation(attacker, defender) {
  if (defender.type === 'artillery' || defender.type === 'bomber') return false; // 防御方不反击
  if (attacker.type === 'artillery') return false;                              // 炮兵攻击，对方不反击
  if (attacker.type === 'bomber' && defender.type !== 'fighter') return false;   // 轰炸机仅遭战斗机反击
  if (defender.has('shock')) return false;                                       // 冲击：目标不反击
  return true;
}
```
配套：**守护/被守护**（§8.1）、**伏击先手**（§8.3）、**重甲减伤**（§8.5）、**冲击免反击**（§8.7）。

### 7.4 谁能打谁（目标合法性）
| 攻击者 | 可攻击的战线 | 额外限制 |
|---|---|---|
| 步兵 infantry | **只能打相邻战线**（本方支援线 ↔ 前线） | 受守护/被守护约束 |
| 坦克 tank | **只能打相邻战线**；可同回合**先移动后攻击**（一次移动 + 一次攻击，顺序任意） | 同上 |
| 炮兵 artillery | **任意战线**（含 HQ），**无视被守护**，不受伤 | — |
| 战斗机 fighter | **任意战线**；**拦截**同战线敌方轰炸机的目标选择 | 受守护约束；**不能具有烟幕** |
| 轰炸机 bomber | **任意战线**（含 HQ），**无视被守护** | 敌方该战线有战斗机时**只能打战斗机** |

- 「相邻战线」= 本方支援阵线 ↔ 前线。**本方支援阵线不能直接打到对方支援阵线**（隔前线）。`[W][F]` **高**
- 所有兵种都可攻击**敌方总部**（不受守护限制）。`[Z][W]` **高**

### 7.5 无法行动的状态
| 状态 | 效果 | 出处 |
|---|---|---|
| 疲惫 | 本回合已行动 | `[Z][W]` **高** |
| 压制 / 被压制 | **不能移动或攻击**；在**拥有者的下个回合结束时**解除 | `[Z][W]` **高** |
| 抑制 pin | **失去所有关键词和效果**，并**重置攻击力、最大防御力、行动花费为原单位数值**；**不会**移除压制/被收缴/被抑制/被控制状态 | `[Z]` **高**（解决此前 ❓7） |
| 隐蔽 | 揭示前不受指令/反制/单位效果影响，行动花费为 1，全部效果不触发（白板） | `[Z]` **高** |
| 无法攻击（卡面） | 如 `38th_independent` | `[D]` **高** |

### 7.6 攻击次数与行动次序
- 默认 **1 次/回合**；`奋战 fury` → **2 次**。`[Z][W]` **高**
- **坦克**：每回合可「移动 1 次 + 攻击 1 次」，顺序任意；有闪击的坦克在部署当回合也能完成这套。`[Z]` **高**
- 单位一旦升为老兵，**本回合已行动过（坦克为已攻击过）且无奋战 → 不能再行动，即使老兵形态有闪击也不行**。`[Z]` **高**

## 8. 关键字全表（机制语义）

> 数量来自 `[D]`；中文名以 `[Z][W]` 与卡面用词为准。详见 `KEYWORDS.md`。
> **官方「对战词条」仅 7 个**：伏击、闪击、奋战、守护、重甲、冲击、烟幕。`[Z]` **高**

### 8.1 守护 guard｜124 张
- 非**炮兵/轰炸机**的敌方单位**只能攻击守护单位**。
- 与守护单位**相邻的非守护单位**无法被轰炸机/炮兵**以外**的单位攻击。
- **当两个相邻单位都具有守护时，两个单位都可以被攻击**。`[Z]` **高**（重要边界）
- 分布：Soviet 39 / Britain 33 / Japan 12 / France 11 / Italy 9 / Finland 8 / Poland 7 / Anzac 4 / **Germany 1 / USA 0**。`[D]` **高**

### 8.2 烟幕 smokescreen｜50 张
- 无法被敌方单位攻击。
- 单位**移动或攻击后失去烟幕**。
- **限制：守护单位和位于前线的单位不能具有烟幕；战斗机不能具有烟幕**。`[Z][W]` **高**

### 8.3 伏击 ambush｜44 张
- 每回合**首次被攻击**时，**首先造成反击伤害**；若攻击单位因此被消灭，则其无法对伏击单位造成伤害。
- **对无法反击的单位无效**（如炮兵、轰炸机攻击步兵/炮兵/坦克时）。`[Z]` **高**
- 优先级**低于冲击**。`[W]` **高**

### 8.4 闪击 blitz｜196 张
- 可在**部署的同一回合行动**。`[Z][W]` **高**

### 8.5 重甲 heavyArmor 1/2/3｜39/11/1（共 51）
- 单位**交战时**受到的伤害 −N；**每单位最多 3 点**。
- **步兵和炮兵没有重甲**（`[D]` 验证：infantry 0 / artillery 0；tank 37 / bomber 13 / fighter 1）。
- **重甲不减免指令伤害**（`kv2` 是特例反证）。`[Z][W]` **高**

### 8.6 奋战 fury｜44 张 —— 一回合攻击两次。`[Z][W]` **高**

### 8.7 冲击 shock｜32 张
- **主动攻击时不受反击伤害**，**用一次后失效**；可再被赋予。`[Z][W]` **高**

### 8.8 收缴 salvage｜9 张
- **收缴**：友方回合中，具有收缴的卡牌**消灭敌方单位时**，将被消灭单位的 **1/1 复制加入手牌**，并标记为「被收缴」，**费用至多 3 点**。
- **被收缴**：与收缴它的卡牌**同国**，属性 **1/1**，**保留原单位所有效果**。`[Z]` **高**（解决此前 ❓10）

### 8.9 被收缴（状态）
见 §8.8 第二段。可被卡面引用：「友方被收缴单位具有 −2 花费」。`[D]`

### 8.10 动员 mobilize｜8 张
- 回合开始时 **+1/+1**；**受到伤害后失去动员**。`[Z][W]` **高**

### 8.11 钳击 pincer｜15 张
- 部署时选择**另一个友方单位**作为钳击同伴，两者获得钳击加成，**直到一方离场或失去钳击**。
- **一个单位离场后，另一在场单位永久失去该钳击效果**。`[Z][W]` **高**

### 8.12 隐蔽 covert｜11 张（CovertOps 扩展 100%）
- 入场时**背面朝上**；**揭示前不受指令、反制或单位效果影响**，**行动花费为 1**。
- **发起攻击或被攻击后揭示**并失去隐蔽。
- **揭示前所有效果都不触发**（等同白板）。
- 揭示后触发「**揭示：**」效果（卡面句式）。`[Z]` **高**（解决此前 ❓9）

### 8.13 老兵 veteran｜44 对（`BecomesVeteran:` / `VeteranOf:`）
- 满足条件后升为老兵：**重置费用、攻击力、防御力**。
- 老兵是同一张牌的**另一个形态**，仍是单位；**被抑制时会变回原形态**。
- **老兵牌属衍生卡**（`[D]`：44 张 `VeteranOf:` 卡全部 `is_derived=true`、`pool=derived`），**不可构筑**。
- 升阶当回合若已行动过且无奋战 → 不能再行动（即使老兵有闪击）。`[Z]` **高**（解决此前 ❓15）
- 触发条件句式 5 类见 `KEYWORDS.md` §3。

### 8.14 情报 intel 1/2/3｜11/9/4（共 24）
- **使用时显示敌方 X 张手牌**（变为「明牌」）。`[Z]` **高**（解决此前 ❓8）
- **明牌规则**：被明确加入手牌的卡会成为明牌；**明牌被洗入/置入卡组后失去明牌状态**，再抽上来就不是明牌。`[Z]` **高**
- 溢出：卡面「每溢出 1 情报」→ 敌方手牌不足 X 时会产生溢出量。`[D]` **中**

### 8.15 协力 bond｜26 张（Homefront 96%）
- **使用协力卡牌时，若「本回合开始时」场上没有相同国家的友方单位 → 总部受到一次疲劳减益（负面效果）**。
- 判定锚点是「**本回合开始时**」：若回合开始时已有同国友方单位，即使本回合全部送掉也不触发。`[Z]` **高**（解决此前 ❓11）

### 8.16 山地 alpine｜18 张
- 山地单位**部署或加入战场时**，每有 1 个其他友方山地单位，获得一次 **+1/+1**。`[Z][W]` **高**

### 8.17 流亡 exile（`is_exile` 16 张 / `host_factions` 机制）
见 §4.1。`[Z]` **高**

### 8.18 OnlySpawnable（API 怪癖，非游戏内词条）
见 §4.2 ⚠️。**不要**实现为「不可打出」。**高**

## 9. 反制指令（Countermeasure）

- 独立卡牌类型（`type=countermeasure`，51 张），**不是单位**，不占单位槽。`[D]` **高**
- **可在手中激活**（面朝下），**敌方无法查看**；**触发前对方无法知道你激活了哪些反制**（除非用「帝国之力」弃掉）。`[Z][W]` **高**
- 激活后**在敌方回合达成条件即触发**。`[Z][W]` **高**
- 花费隐蔽：激活时你花费的指挥点对方看不见。`[W]` **高**
- **可主动取消激活**（用已激活的反制可取消其激活状态）。`[W]` **高**
- **反制指令 ≠ 指令**：如「抽两张指令」不能抽到反制。`[Z]` **高**（重要过滤规则）
- **苏联和日本没有反制**（`[D]` 验证：Soviet 0、Japan 0）。分布：Britain 18 / Germany 17 / USA 8 / Finland 5 / Poland 2 / Italy 1。`[Z][D]` **高**
- 触发条件句式与钩子（`[D]` 全量统计）：
  - `on_enemy_deploy`：`night_hunters`、`careless_talk`、`airstrike`、`stranglehold`、`ski_troops`
  - `on_unit_attack`：`scatter_tactics`、`entrapment`
  - `on_move_to_frontline`：`missing`、`envelop`
  - `on_enemy_order`：`foiled_plans`
  - `on_enemy_extra_draw`：`lightning_strike`
  - `on_own_hq_damaged`：`retaliation`、`heartland_defense`
- 反制可被反制/屏蔽：`c6n_saiun`「双方反制无法触发」、`lublin_rxiii`「揭示 1 个隐蔽单位」。`[D]` **中**
- 反制区容量：`[Z][W]` 未给出上限；`[F]` 建模为独立无上限列表。❓ **低**

## 10. 卡牌类型与「海军」定义

| type | 数量 | 攻击/防御范围 | 目标规则 |
|---|---|---|---|
| `order` 指令 | 636 | 0/0 | 一次性；**注意「指令」不含反制** |
| `infantry` 步兵 | 527 | 0–9 / 1–10 | 仅相邻战线；无重甲 |
| `fighter` 战斗机 | 141 | 0–7 / 1–7 | 任意战线；拦截轰炸机；不能有烟幕 |
| `tank` 坦克 | 139 | 0–12 / 1–10 | 相邻战线；可同回合移动+攻击 |
| `bomber` 轰炸机 | 95 | 1–9 / 1–9 | 任意战线；受战斗机限制；不反击 |
| `artillery` 炮兵 | 57 | 1–6 / 1–6 | 任意战线；无视被守护；不受伤；无重甲 |
| `countermeasure` 反制 | 51 | 0/0 | 见 §9 |

- **空军 = 战斗机 + 轰炸机**（236 张）。`[Z]` **高**
- **数据集中不存在** `destroyer`/`battleship`/`submarine`/`naval` 等类型。`[D]` **高**
- **「海军」的判定规则（`[Z]` 明确给出）**：只有**名称格式为「字母+xx 号」**或**纯字母+数字的舰艇/潜艇**才算海军。
  - ⚠️ **名字里带「海军」的不是海军**，例如「海军力量」。`[Z]` **高**
  - 海军是 `NavalWarfare`（海战）赛季新增的**标签**，且**此前的老海军卡也被补贴标签**。`[Z]` **高**
  - 实现建议：`is_naval(card)` 用命名正则（如 `^[A-Za-z]{1,4}[ -]?[\w\s\.\-]*号$`、`^U-\d+`）或维护显式标签表。
- 最高身材：`maus` 12/10（kr12，重甲 3）、`king_tiger` 10/10。`[D]` **高**

## 11. 牌堆耗尽 / 随机性 / 胜负

- **疲劳减益（士气伤害）**：卡组为空时抽牌，**总部失去防御力**；**第 1 次 1 点，第 2 次 2 点**，依次递增。`[Z][W]` **高**
  - 卡面并不使用「疲劳」二字（`疲劳` 在卡面出现 0 次），仅在协力条款中以「疲劳减益」指称。`[D]` **高**
- **牌库**：39 张洗牌；调度替换牌洗回后随机补抽。`[Z][W]` **高**
- **随机性**：大量「随机」（随机弃牌、随机目标、随机生成）。需**种子化 PRNG** 以便回放测试。`[D]` **高**
- **胜负**：敌方总部防御力 ≤ 0 → 胜。`[Z][W]` **高**
- **平局**：无公开条款。建议：同时归零 → 平局。❓ **低**
- **投降**：`[Z]` 未写；实现为立即判负。❓ **低**
- **回合上限**：无；士气伤害单调递增保证收敛。**中**
