# 更新日志

## 2026-11-08 · 交互与性能优化（进行中）

- **修复：指令无法指向单位** —— 选中有目标指令后，点击高亮单位不生效的问题（点击分发只在攻击态提交目标）。
- **修复：卡片预览不自动消失** —— 悬停 1s 出现的检视面板，鼠标移开自动收起；点击打开的保持。
- **新增：开局卡图预缓存** —— 对局开始前预载双方牌组前 10 张卡图（带进度浮层），后台继续预载其余卡牌；对局结束释放缓存。
- **性能**：卡牌图鉴窗口化渲染、zustand 选择器 / `useShallow`、动画只使用 `transform/opacity`（详见 `docs/PERF.md`）。
- **P2P 联机调研 + PoC**：静态站点（GitHub Pages）下无服务器联机的可行方案（详见 [`docs/P2P.md`](P2P.md)）。
  - 结论：可行；房主权威 + PeerMessage 协议不变，只把传输层换成 WebRTC DataChannel。
  - P0 手动「对战码」（~800 字符，复制两次，零后端、100% 可用）；P1 公共 MQTT 信令自动交换（AES-GCM 加密载荷，实测 2.1s 握手）；P2 可选自建 TURN 兜底对称 NAT。
  - 实验页：`#/p2p`（`src/pages/P2PTestPage.tsx` + `src/net/p2pTransport.ts` + `src/net/p2pSignal*.ts`）；默认不放进导航，仅供验证。

## 2026-11-07 · V5 修复与体验优化

- 修复「不能攻击敌方单位」：战场点击敌方单位只触发检视、未提交攻击目标。
- 守护词条：守护单位左右相邻单位被守护、无法被攻击；守护单位自身可被攻击；炮兵/轰炸机无视守护。
- 闪击词条：部署当回合可移动或攻击；非闪击单位召唤病（灰显 + 提示）；修复闪击被误判为召唤病的问题。
- 总部卡片化：支援阵线外侧灰色 HQ 卡，显示主国中文名 + 实时血量/护甲，受击闪红，不可移动；敌方 HQ 可被攻击（脉冲+准星）。
- 卡片检视候选框：点击或悬停任意卡片，右下角显示卡图、名称、词条、部署/行动花费、血量、攻击、护甲与状态。
- 部署位置自选：选中手牌单位进入布防模式，点击支援线 4 个槽位决定位置（Esc/右键取消）。
